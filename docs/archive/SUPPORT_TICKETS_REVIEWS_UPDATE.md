# Support Tickets and Private Reviews

## Member support center

A new `/support` page contains:

- Support Tickets
- Leave a Review

Ticket categories cover billing, subscriptions, fulfillment, Steam trades,
upgrades, rewards, community moderation, account access, privacy/account
deletion, technical issues, and general support.

Members can see their own ticket history and admin responses.

## Private reviews

Members select 1–5 stars and leave written feedback. Reviews are private and
visible only in the Admin Operations Hub. Submitting again updates the member's
existing review.

## Admin Operations Hub

Two new tabs are available:

- Tickets
- Reviews

Admins can filter tickets, update status, write a member-visible response, and
review all private ratings and feedback.

## Installation

Run `supabase/2026-08-support-tickets-private-reviews.sql` once in Supabase.
