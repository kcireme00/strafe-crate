# Mobile navigation

Desktop navigation remains unchanged.

At 900px and below, the horizontal navigation is replaced with a compact menu
button. Opening it displays a left-side drawer with:

- Memberships
- Dashboard
- Rewards
- Community
- Support
- Settings
- Admin-only links when applicable
- Log out

The drawer highlights the current section, closes after navigation, closes when
the overlay is tapped, and uses icon-free text links for maximum clarity on
small screens.
