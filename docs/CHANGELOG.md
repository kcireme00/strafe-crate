# Changelog

This repository was consolidated from an iterative development build.

Historical implementation notes were moved to `docs/archive/` so the project root only contains current project-level files.

Current feature set includes:

- account-linked Stripe checkout
- first-of-month billing behavior
- membership upgrade/downgrade scheduling
- fulfillment and multi-skin support
- dashboard and member card
- XP, rewards, and trophies
- community chat, reports, bans, and moderation
- support tickets and private reviews
- threaded support workflow
- permanent account deletion
- mobile navigation drawer
- social links
- business metrics
- Sand Dune launch event
