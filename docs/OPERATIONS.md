# Operations Guide

## Monthly membership cycle

- Subscription billing occurs on the 1st according to the current billing logic.
- Membership changes are scheduled for the next cycle rather than rewriting an already-active fulfillment cycle.
- Fulfillment is managed from the Admin Operations Hub.
- Steam trade delivery is manually verified.

## Fulfillment

Use the Orders tab to:

- review member and cycle information
- assign skin / exterior
- save acquisition cost
- track trade status
- mark fulfillment complete

Saving an order is not blocked by a missing Steam Trade URL; the URL remains an operational warning rather than a database save requirement.

## Support

Members may keep one active support ticket at a time. Tickets use threaded replies. Closing/resolving a ticket allows another ticket to be created.

Admins may:

- reply
- change ticket status
- archive
- close
- disable/restores a member's ticket access

## Community moderation

Admin moderation includes reports, bans/timeouts, message actions, and permanent restrictions.

## Launch event

The Sand Dune launch event uses:

- Steam username claim
- saved Steam Trade URL
- manual admin verification
- P250 | Sand Dune fulfillment order
- Sand Dollar trophy
- participant counter

See the event migration under `supabase/`.
