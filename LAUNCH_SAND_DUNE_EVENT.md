# September 2026 Sand Dune launch event

## Homepage

- Hero headline now explicitly says CS2.
- Compact `EVENT BELOW` banner links to the event section.
- Event section awards a P250 | Sand Dune and exclusive Sand Dollar trophy.
- Members must confirm their Steam username includes `StrafeCrate.com`.
- A saved Steam Trade URL is required before submitting.
- Live participant counter includes pending, approved, and fulfilled claims.

## Admin

The Operations Hub has a new Events tab.

Approving a claim:
1. Grants the Sand Dollar trophy.
2. Creates a P250 | Sand Dune fulfillment order.
3. Links the event claim to the fulfillment order.

When that order is marked trade sent, accepted, or fulfilled, the event claim
automatically becomes fulfilled.

## Installation

Run `supabase/2026-08-launch-sand-dune-event.sql` once.
